# Intelligent Engineering Knowledge & Workflow Assistant

A production-style agent that reasons over private engineering notes (RAG via Qdrant),
calls typed external tools under an explicit authorization policy, and defends against
prompt injection and tool abuse.

See `docs/overview.md` for what this demonstrates and how to run it locally, and
`docs/architecture.md` for the system design.

## Status

Phase 1 (Foundation) in progress.
